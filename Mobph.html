为什么是 Mobph

自研编译器 · 官方工具链 · 零第三方依赖

01

极简语法

缩进即结构，一行一个控件。写界面像写 Markdown，不需要 XML 或样板代码。

02

原生性能

编译为原生 Android 视图，不是 WebView 套壳。滑动流畅，启动迅速。

03

一条命令

mobph build app.mob 从源码到签名 APK，自动完成全流程。

04

自研编译器

词法、语法、语义分析、代码生成全部自研。不依赖任何第三方 DSL 框架。

05

完整工具链

内置图标生成、文件关联、编译诊断。开箱即用的开发体验。

06

Windows 友好

在 Windows 上完成开发和编译。无需 Mac，无需 Linux。

语法一览

读完这段代码，你就学会了 Mobph

// 一个带状态、可交互的待办应用
app "TodoApp"
  icon  "assets/icon.png"
  title "我的待办"

page Home
  column fill #F2F2F7 padding 16

    text "我的待办" size 28 bold color #000

    card fill #FFFFFF radius 12 padding 16 shadow 4
      input "输入新任务" bind task fill #F5F5F5 radius 8
      button "添加" fill #007AFF textColor #FFF radius 8
        when tapped
          toast "已添加：{task}"
          set count = count + 1

    switch "接收通知" bind notify
      when changed
        toast "当前状态：{value}"

三步开始

Windows · macOS · Linux

1

下载并解压

从下载页面获取 Mobph.zip，解压到任意目录。

2

安装

需要 Python 3.10+。进入目录执行 pip install -e . 完成安装。

3

编译运行

写一个 app.mob，执行 mobph build app.mob 得到 APK。
