Java 环境准备

💡 无需手动配置环境变量 Viskluke 内置了强大的 Java 扫描引擎。只要你安装了 Java 17，启动器会自动帮你识别并填入路径，不需要懂命令行。

1. 去哪下载 Java 17？

点击直达官方下载页：Adoptium 官方下载 (Windows x64 .msi)

2. 怎么安装？

双击下载的 .msi 文件，一路点击 Next (下一步)，最后点击 Finish 即可。保持默认设置，不要去改那些看不懂的选项。

3. 启动器没识别到怎么办？

  • 在启动器实例设置页，点击 Java 路径 旁边的 “自动检测”。
  • 若仍失败，手动填入默认路径：C:\Program Files\Eclipse Adoptium\jdk-17.x.x-hotspot\bin\javaw.exe

快速上手教程

第一步：登录账号

打开启动器，点击左上角头像。选择 离线登录，输入你想要的英文名（如 Steve），点击确认即可。

第二步：下载游戏版本

  • 点击左侧菜单 下载 -> 游戏版本。
  • 在搜索框输入版本号（如 1.20.4），点击右侧 创建实例。

第三步：启动游戏

画面跳回 游戏 页后，点击右上角 启动游戏。首次启动会自动从官方源下载几百兆的核心文件，请耐心等待进度条跑完。

第四步：导入整合包或模组

在 下载 页面的 Mod / 整合包 标签下，直接搜索你想要的模组名字，点击安装，Viskluke 会自动下载并放入当前选中实例的 `mods` 文件夹。

异地联机指南

无需公网 IP，无需折腾路由器端口映射，只需两步即可让异地好友进入你的世界。

房主（你）的操作：

  1. 进入单人游戏，按 Esc 键，点击 对局域网开放，记下聊天框提示的端口号。
  2. 切回启动器，点击左侧 服务器。
  3. 在下方内网穿透区域，点击 开隧道，将生成的房间号发给朋友。

玩家（朋友）的操作：

  1. 在启动器的 服务器 页面，点击 加入房间，输入你发的房间号。
  2. 打开游戏，进入 多人游戏，直接连接地址 127.0.0.1 即可进入。
💡 进阶提示：开服与专属域名 如果你是服主，可以直接在启动器点击 启动服务器。通过 Viskluke Address，填入前缀即可获得类似 myworld.stde.eu.cc 的专属域名，朋友直接用域名直连，免去记 IP 的烦恼。

常见报错排查

❌ 安装失败 / 点击安装没反应 原因： 系统权限不足，或者被安全软件静默拦截。
解决： 找到下载好的安装包，右键点击它，选择“以管理员身份运行”。如果还是没反应，请暂时退出 360 或火绒。
❌ UnsupportedClassVersionError 原因： Java 版本不匹配。
解决： 安装 Java 17，并在实例设置中把 Java 路径指向新版本。
❌ 文件被占用 / EPERM 原因： 杀毒软件拦截写入。
解决： 将启动器和游戏目录加入杀毒软件白名单。
❌ Address already in use 原因： 端口被其他程序占用。
解决： 在服务器页将端口从 25565 改为 25566。
❌ 内存不足 / OutOfMemoryError 原因： 分配的内存太小，或者装了太多重型模组。
解决： 在实例设置里，把最大内存从 2G 调大到 4G 或 6G（取决于你电脑的物理内存）。
